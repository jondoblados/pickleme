Slot grid. Times run down, courts run across. Tap to select; drag selects a block. Selections must be whole slots, contiguous per court, within the opening hours.
Booking window. Dates beyond the facility's window (here 7 days) are dimmed and show when they open, e.g. "Opens Sat 14 Nov, 12:00 am".
Other groups. Organisers see that a slot is Booked or On hold but not who holds it, unless it is their own group.
Allowance. Weekly court-hour limit set by the facility admin for each organiser. Holds count against it until released.
Hold then confirm. Holding reserves the slots in one database transaction. Confirm turns the hold into a booking and can create the linked game in the same step.
