Rules are versioned. Each booking stores the rule set it was made under, so changing the cutoff later doesn't change existing bookings.
Closures never silently overlap. Adding a closure lists every affected booking first. The admin picks move or cancel for each; nothing is saved until all are resolved.
Move suggestions. A booking can only move to a court that is free for the same time, checked by the same database rule that stops double booking.
Notifications. Affected organisers are emailed. If a linked game is cancelled, its players get the usual cancellation email.
